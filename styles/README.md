# Chronicle Studio · 历史与科普视觉风格目录

带 `✦` 标记的风格**属于 AI 同源插画管线**：所有人物、载具、建筑及艺术场景画幅必须由 `image-generator` 按本风格锚点绘制（或通过绿幕精灵表由 `chroma_extract.py` 自动提取），**严禁使用简陋程序几何块拼凑充数**。未标 `✦` 的风格可直接由 Canvas 2D / WebGL / SVG 高精度代码生成主体。

## 使用与定制说明

- **Phase 1 选型**：禁止凭文字表格盲选；由 `style-visual-pk` 围绕你的当前剧本真实渲染 3～4 张风格样例图后看图决定。
- **自定义风格目录**：按照 [MY-STYLES.md](../MY-STYLES.md) 定制并通过定妆验收的个人风格，保存在 `styles/custom/<slug>/` 下（不会影响上述 8 个官方基准包）。
