# Apple 级状态变化驱动动效规范 (Apple-Grade State-Change Motion Spec)

不要去按“有哪些组件”机械堆特效，而要严格**按照界面和画面中发生的每一个“状态变化（State Transition）”做动效设计**。好动效是在**解释因果（从哪来、到哪去、和谁有关）**，而不是装饰品。

---

## 1. 全片统一节奏阶梯（Motion Scale）

全片所有动作共享同一套曲线语言，绝不允许镜头 1 自己写一套弹性公式、镜头 3 又换另一套突兀瞬跳。

| 层级常量 | 无 BPM 默认值 | 锚定节拍换算（如 `80 BPM`：1拍=`0.75s`） | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **`T_MICRO`** | `0.18 s` | `1/4` 拍 (`0.1875s`) | 印章触压落墨、引线端点发光点亮、细微震颤回正 |
| **`T_UI`** | `0.36 s` | `1/2` 拍 (`0.375s`) | 批注标签入场、小型数据芯片切换、图标形态切换 |
| **`T_MORPH`** | `0.52 s` | `~3/4` 拍 (`0.55s`) | 右上角状态卡文本与色条变型过渡、日历翻页折叠 |
| **`T_TRANS`** | `0.75 s` | `1` 整拍 (`0.75s`) | 水彩/墨水擦除跨场景衔接、章节标题进退场 |
| **`T_GLIDE`** | `1.50 s` | `2` 整拍 (`1.50s`) | 地图跨区域长距离推近/拉远、核心镜头聚焦定格 |

对应现成库：`core/lib/motion.js` 中的 `MOTION_DUR` 与 `beatScale(bpm)`。

## 2. 九类“状态变化”标准拆解清单

制作分镜与编写 `render(t)` 时，对下列每一项变化都要能说清楚来龙去脉：

1. **出现（Appear）**：
   - *禁止*：生硬 `opacity: 0 -> 1` 瞬亮，或极低俗的 `scale(0.001) -> scale(1.0)` 塑料弹跳。
   - *规范*：使用 `easeOutQuint(u)` 或无过冲解析弹簧 `criticallyDampedSpring(dt, tau)`，配合 `12–24px` **向着视觉落点的微位移 + 0→1 渐显 + 柔性裁剪展开**（画笔笔触或毛细渗墨边）。
2. **消失（Disappear）**：
   - *规范*：退出速度永远比入场略快（约 `0.75× T_UI`），朝**离场方向或起源点轻退**并同步降透明度，绝不突然从屏幕抹掉。
3. **移动（Move / Pan）**：
   - *规范*：短程直线平移用 `easeInOutCubic`；跨场景多点运镜（3 个以上路标点）必须经由 `QuinticHermiteSpline` 计算 5 次多项式插值，确保位置、速度与加速度三阶连续，**驻留点前后的加速/减速无陡坎**。
4. **变大小（Resize / Focus）**：
   - *规范*：卡片内容增减引起高度宽度变化时，外框先于文字平稳伸缩（同圆角跟随缩放），保持文字居左或锚定基线稳定不重排闪烁。
5. **换内容 / 数值跳动（Content Swap / Data Tick）**：
   - *绝对红线*：**杜绝旧文字与新文字在居中同坐标直接交叉透明导致“重影叠字”！**
   - *规范*：调用 `core/lib/motion.js` 的 `textCrossfadeWeights(u)`：
     - `u ∈ [0.00, 0.42]`：旧文案向微上/微左侧平滑淡出至 `alpha = 0`；
     - `u ∈ [0.42, 0.52]`：留出极短的视觉呼吸喘息空窗；
     - `u ∈ [0.52, 1.00]`：新文案由 `alpha = 0` 稳落至 `1`，同一时间外框底色与数值比例条持续平滑过渡。
6. **图标与印章切换（Icon Morph / Stamp）**：
   - *规范*：印章与标志压入时，利用微尺度（`1.10 -> 1.00` 的克制压落而非 `0.001` 弹出）配合细微纸面回弹阴影变化，落定当刻在 `window.EV` 埋入音效 Cue。
7. **防碰撞让位（Collision Repulsion）**：
   - *规范*：多个标签、悬浮框或标注接近安全区边缘或相互靠近时，用 `resolveCardRepulsion` 平滑插值分离间距，最大单帧让位步幅有上限（不抖动、不闪跳）。
8. **景深与光影过渡（Depth & Lighting Shift）**：
   - *规范*：镜头靠近局部细节时，景深模糊与背景对比收敛随距离连续渐变；若剧情由平和转为战争危机，背景纸色饱和度与光照色温沿 1～2 小节曲线沉降。
9. **无障碍减动效开关（Reduced Motion）**：
   - *规范*：在 URL 查询参数 `?reducedMotion=1`（由 `isReducedMotion()` 读取）开启时，关闭一切镜头大位移抖动、震颤后坐力与复杂缩放，统一降级为优雅缓慢的 `0.25s` 柔和淡入淡出。

## 3. 自检三问（每次 Render 前核查）

1. 镜头停留期间是否“完全死屏”？（除定格读数特写外，建议维持极微弱如 `1–2 px/s` 的有机呼吸漂移。）
2. 是否有任何卡片切换或文字更改出现过双影或突然闪烁？
3. 相邻两镜头的起止切线方向是否一致？（不要上个镜头正在高速向左横移，下一镜突然毫无过渡强行向下俯冲。）
