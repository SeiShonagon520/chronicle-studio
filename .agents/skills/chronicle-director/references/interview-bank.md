# 标准交互问答词库与“模糊感受翻译表” (Interview Bank)

本参考文件供 `chronicle-director` 在 Phase 0～3 使用。提问铁律：**每轮不超过 4 个问题、永远用 `ask_question` 给 2～4 个带后果对比的直白选项、允许用户回复“按推荐来”或写大白话。**

---

## 一、“说不清怎么表达”时的模糊感受翻译表

当用户在审图后反馈抽象感受，或初期不知如何表达喜好时，**不要反问“那你具体想改哪个参数？”**，直接按此表提供可选项：

| 用户可能说的话 | 可能对应的实际问题诊断 | 应该给用户的 2~3 个直白调优选项 |
| :--- | :--- | :--- |
| **“感觉有点假 / 很玩具 / 廉价感”** | 出现了代码硬画的低精度几何替代物，或缺乏明暗与材质纸纹 | A. 彻底改用全 AI 手绘分层图（杜绝代码画角色建筑）<br>B. 降低纯色鲜艳度，全面加入纸张纤维/墨迹与阴影深度<br>C. 改走高精度极简信息图风（像 Vox/BBC 杂志） |
| **“太割裂了 / 像不同作品拼一起的”** | 各镜头美术来源不统一，或硬切转场缺乏视觉过渡桥梁 | A. 用同一套提示词锚点统一重绘全部分镜素材<br>B. 所有切镜改由运镜衔接或媒介擦除（墨水晕染/纸页推拉）<br>C. 取消独立 HUD 重框，让标签、文字“印”在同一张纸底上 |
| **“动起来有点生硬 / 像 PPT 幻灯片”** | 使用了 `linear` 或粗糙缩放弹性，文本变换重影，转场死停 | A. 引入 Apple 级临界阻尼缓入 + 防重影文字交替<br>B. 给所有“静止停留镜头”注入极缓慢的微呼吸推拉漂移<br>C. 改为一镜到底空间样条运镜 |
| **“信息太乱 / 看不过来”** | 同时出现多个高饱和组件、标注盖住主体或字幕停留不够长 | A. 精简同屏元素，任何瞬间只保 1 个视觉焦点 + 1 组注释<br>B. 加大安全区留白，字号拉大并放慢停留驻留时长<br>C. 弱化背景底图对比度，让文字自然浮出 |

## 二、分阶段聚焦提问模板

### Phase 0（选题与路线分诊，最多 4 题）
1. **画幅与发布渠道**：
   - `1920×1080 横屏（B站/YouTube 标准，预留弹幕/进度条安全区）` *(Recommended)*
   - `1080×1920 竖屏（抖音/小红书/B站竖屏，重点居中上下留空）`
   - `1080×1440 竖版绘本比例`
2. **预计时长与分幕策略**：
   - `45～60 秒单幕精华短片（节奏紧凑，一次性全流程交付）` *(Recommended)*
   - `2～6 分钟多幕深度片（按每幕 45～60 秒拆工程，先做 Pilot 再逐幕推进）`
3. **声音与节奏源**：
   - `我有现成音乐或配音时间轴（需严格按节拍卡点）`
   - `AI 中文旁白配音 + 原创轻配乐 + 真实环境音效` *(Recommended)*
   - `无旁白纯器乐 + 大号杂志级字幕解说`
4. **首轮风格大方向倾斜（决定 Phase 1 出哪 4 组看图样例）** *(支持多选)*：
   - `法式水彩/手绘绘本质感` / `历史档案/泛黄电报纪录片质感` / `高精动态战略地图（Vox/维基纪录流）` / `复古漫画剪纸质感`

---

### Phase 2（细节、HUD 与 Apple 动效锁定，1～2 轮）
1. **画面底色极性与氛围定调**：
   - `做旧暖羊皮纸浅底（适合绘本、历史书卷、舒适耐看）`
   - `冷暗博物馆/暗房灯箱深底（适合悬疑档案、夜晚战役、战况推演）`
   - `随剧情起伏动态冷暖切换（平和期暖纸 → 战火危机渐沉为暗灰冷青）` *(Recommended)*
2. **屏幕信息与 HUD 轻重度**：
   - `极简无框融入纸面（仅时间日期小戳 + 细引线地名 + 底部干净字幕）` *(Recommended)*
   - `轻度战报卡片流（右上角含柔和边框状态对比卡，状态切换丝滑变形）`
   - `档案调查满配版（时间轴标尺 + 红线批注 + 印章 + 对比柱状图）`
3. **镜头衔接核心习惯**：
   - `空间连续一镜推拉为主（同一张大画布或世界地图连续走位，最小化硬切）` *(Recommended)*
   - `物理介质自然擦除切换（硝烟/水彩渗墨/纸页翻动顺滑换场）`
   - `混合编排（平时一镜丝滑联动，仅在高潮转折处保留 1～2 次卡拍骤停与切镜）`
4. **动效质感偏爱**：
   - `苹果级克制阻尼（快出慢落无过冲、绝不滥用弹出缩放，稳重高级）` *(Recommended)*
   - `物理纸艺微弹性（像真正在桌面上拍下、挪动、翻转实体卡片）`

---

### Phase 3（叙事结构三选一模板）
必须围绕当前具体题材给出 3 个有明确差异的方案，格式如下：
- **结构 A（以小见大微观切入）**：以某件真实实物/细节开场，抽丝剥茧回望宏大时代（如《一张电报如何引爆整块大陆》）；
- **结构 B（时间差与对峙张力）**：围绕对立双方的误判与倒计时并线推进；
- **结构 C（单一空间演进史）**：镜头不离开同一块历史地图桌/街道视角，通过介质层层覆盖演绎变迁。
